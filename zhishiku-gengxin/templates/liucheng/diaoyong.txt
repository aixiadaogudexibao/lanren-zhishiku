# 调用树（diaoyong）· 接题 → 探针 → 调技术树

> 职责：**只做"根据题目思路选技术/选路径"**，不写任何技术步骤/命令/偏移。
> 技术本体在 `shu/<标号>.md`；清单在 `jineng.txt`；门控在 `menkan/workflow.xml`。

## 0. 怎么用
```text
接题 → 先跑 T.0（识别保护/段/libc）
     → 用"探针"观察题目，得到每个探针的值
     → 按"路由规则"匹配（多探针可组合；命中多个可能形成一条链）
     → 调 shu/<技术>.md，从它标注的"入口"走（可只走其中一段）
```

## 1. 探针集（可观察量）
> 探针 = 对题目的一个可观察量做判定。多个探针**叠加**使用，不是互斥 if-else。

| 编号 | 探针名 | 观察什么 |
|---|---|---|
| P1 | 保护 | checksec |
| P2 | 结构 | 菜单/指针槽/全局缓冲 |
| P3 | 漏洞形态 | free 行为/边界/size 上限/UAF |
| P4 | 输出 | stdout 行为 / show 是否可用 |
| P5 | 沙箱 | seccomp |
| P6 | 地址 | ASLR/PIE/可泄漏面 |
| P7 | 输入语义 | 输入怎么被用 |
| P8 | 目标环境 | 内核/用户态/附件 |

## 2. 路由规则（探针组合 → 技术 / 路径）
> 写法：`[P?:值] ∧ ... → 标号（调哪些段）`。`※` 注明"只需部分路径"。

```text
[always]  → T.0
（在此按领域补：堆/栈/格式化/内核/VM 的路由行）
```

|---|---|---|
